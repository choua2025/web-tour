# Travel Plan Admin Portal

This is a comprehensive, modern admin dashboard built with Nuxt 4, Vue 3, **Tailwind CSS**, and **Chart.js**.

## 🛠️ Admin Pages Included:
- **Admin Dashboard**: Real-time stats and booking trends with Line Charts.
- **Manage Users**: Full CRUD functionality for accounts.
- **Manage Destinations**: Grid view with high-res image previews.
- **Manage Tours**: Experience cataloging and pakcage organization.
- **Manage Hotels**: Global partner network management.
- **Manage Transport**: Multi-modal logistics coordination.
- **Manage Bookings**: Real-time reservation ledger.
- **Manage Payments**: Audited transaction history.
- **Manage Reviews**: Sentiment and vocal feedback moderation.
- **Reports & Analytics**: Advanced business intelligence with Bar and Donut Charts.
- **System Governance**: Profile and node configuration.

## 🎨 Design Features:
- **Tailwind CSS Powered**: Utility-first architecture for rapid, optimized styling.
- **Premium Aesthetics**: Deep dark mode, glassmorphic effects, and fluid transitions.
- **Data Visualization**: Real-time data rendering via Chart.js for actionable insights.
- **Responsive Architecture**: Fluid layout from mobile to ultra-wide displays.

## 🚀 Technology Stack:
- **Nuxt 4 / Vue 3**
- **Tailwind CSS**
- **Chart.js / vue-chartjs**
- **Lucide Icons**
- **Google Fonts (Outfit)**

Look at the [Nuxt documentation](https://nuxt.com/docs/getting-started/introduction) to learn more.

## Setup

Make sure to install dependencies:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev

# pnpm
pnpm dev

# yarn
yarn dev

# bun
bun run dev
```

## Production

Build the application for production:

```bash
# npm
npm run build

# pnpm
pnpm build

# yarn
yarn build

# bun
bun run build
```

Locally preview production build:

```bash
# npm
npm run preview

# pnpm
pnpm preview

# yarn
yarn preview

# bun
bun run preview
```

Check out the [deployment documentation](https://nuxt.com/docs/getting-started/deployment) for more information.
